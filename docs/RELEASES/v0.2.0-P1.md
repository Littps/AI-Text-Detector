# v0.2.0-P1 版本状态说明

> 状态：概念验证阶段（Concept / Pre）

## 关于 pre

本文中的 **pre** 描述的是软件成熟度，表示项目仍处于概念验证和持续开发阶段，
不代表 GitHub Release 页面中的 “Pre-release” 发布类型。

当前版本用于功能验证、技术评估和问题发现，不应被视为成熟稳定版本，也不建议
作为生产系统、商业决策或高可靠性场景中的唯一判断依据。

## 当前可用范围

- Windows 10 / 11 x64 桌面应用
- 本地 Tauri + Python sidecar + WebSocket 启动链路
- 多引擎文本检测、流式结果、全文高亮和逐句明细
- 模型下载、断点续传、SHA256 校验和存储模式管理
- 模型卸载、自定义模型库和本地文档导入
- 基础服务组件检测、缺失项提示和 CPU/CUDA PyTorch 入口

主体安装包只保证桌面界面、本地 sidecar 和 WebSocket 引导链路可用，不包含
PyTorch、Transformers、推理模型权重或其他大型推理组件。推理能力需要用户根据
硬件条件单独准备运行时和模型。

## 已知限制

- 当前受测试设备、操作系统组合、显卡型号和驱动版本等客观条件限制，尚未完成
  覆盖所有目标环境的系统性兼容性测试。
- 部分功能仍缺少长期稳定性、异常恢复和真实全链路压力测试，包括低配置设备、
  纯 CPU 推理、不同 NVIDIA 驱动组合和干净机器安装场景。
- Fast-DetectGPT、Binoculars 等重型或实验性引擎尚未完成全面参数标定；相关结果
  不应被视为经过充分验证的科学结论。
- Binoculars 的 4bit 量化路径尚未实现；现有默认运行方式对显存有较高要求。
- 模型下载和首次完整性校验依赖网络、磁盘空间及外部模型仓库，可能受镜像状态、
  GitHub/Hugging Face 网络质量和第三方服务变化影响。
- 由于个人精力有限，部分交互细节、辅助功能和边缘场景尚未完善，后续版本可能
  调整界面、配置格式、下载源或运行方式。

## 发布边界

当前主体包不包含模型权重和大型推理依赖。发布或分发时应保留明确的组件下载入口、
版本状态说明和已知限制，不应将基础安装包描述为“开箱即用的完整推理发行版”。
